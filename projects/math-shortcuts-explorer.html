Math Shortcuts Explorer

数学速算巧算探索器

GitHub ↗

A Chinese-language maths learning site for grades 3–4, combining 20 illustrated Cornell-note lessons, worked examples and interactive review tests.
面向三至四年级的数学速算巧算学习网站，结合 20 课康奈尔图文笔记、分步例题与互动复习测验。

Math Shortcuts Explorer helps children in grades 3–4 explore efficient arithmetic through illustrated notes, worked examples and practice. The Chinese-language site brings together 20 lessons across three course areas.

From notes to practice

  • Original illustrated Cornell notebooks include a full-resolution viewer.
  • Each lesson offers four-step worked examples and an optional extension exercise.
  • Seven review groups each contain two ten-question papers, with scoring and explanations.
  • Three full-course papers provide 25 questions each at increasing difficulty.
  • Online tests include a stopwatch that pauses when the page is hidden and stops at submission.
  • Seven illustrated worksheets support A4 printing and PNG downloads.

Built for the browser

The static site uses HTML, CSS, JavaScript and JSON course data, with responsive layouts, keyboard navigation and reduced-motion support. Its learning activities require no account or server database; test answers remain in memory for the current session and are cleared on reload.
