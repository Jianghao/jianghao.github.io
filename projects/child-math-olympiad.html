Child Math Olympiad

儿童奥数 · 举一反三

Visit website ↗ GitHub ↗

Interactive maths practice for primary-school children, with tiered hints, step-by-step solutions and locally saved progress — all usable offline.
面向小学生的互动奥数练习，提供分级提示、分步解法与本地进度保存，支持离线学习。

Child Math Olympiad is a collection of interactive Chinese-language maths exercises for primary-school children. Each practice set encourages children to try a problem themselves before gradually revealing hints and a full solution.

Learning by trying

  • Practice covers speed, meeting and pursuit problems, parity, logical reasoning, scheduling, river crossings and balance-scale puzzles.
  • Three difficulty levels move from warm-ups to more challenging applications.
  • Tiered hints lead to step-by-step solutions, diagrams and answer checks.
  • Explanations use primary-school reasoning: diagrams, invariants and simple arithmetic, rather than equations.

Progress that stays with the learner

Children can write drafts in an on-page notebook and mark problems as solved to earn stars. Names, drafts and progress are saved in the local browser so practice can continue on the next visit.

Offline practice

The overview and exercise pages are static HTML files that can be opened directly in a browser without an internet connection.
