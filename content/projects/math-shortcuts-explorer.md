Math Shortcuts Explorer helps children in grades 3–4 explore efficient arithmetic
through illustrated notes, worked examples and practice. The Chinese-language
site brings together 20 lessons across three course areas.

## From notes to practice

- Original illustrated Cornell notebooks include a full-resolution viewer.
- Each lesson offers four-step worked examples and an optional extension exercise.
- Seven review groups each contain two ten-question papers, with scoring and
  explanations.
- Three full-course papers provide 25 questions each at increasing difficulty.
- Online tests include a stopwatch that pauses when the page is hidden and stops
  at submission.
- Seven illustrated worksheets support A4 printing and PNG downloads.

## Built for the browser

The static site uses HTML, CSS, JavaScript and JSON course data, with responsive
layouts, keyboard navigation and reduced-motion support. Its learning activities
require no account or server database; test answers remain in memory for the
current session and are cleared on reload.
